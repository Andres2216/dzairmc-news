# DzairMC News - Upgraded React Native + Expo Application

Official Mobile Application for DzairMC News.

## Tech Stack
- **Expo SDK**: 52/56
- **React Native**: 0.85.3
- **React**: 19.0.0
- **TypeScript**: Strict Mode
- **AdMob**: react-native-google-mobile-ads (Banner, Interstitial, App Open)
- **Target Platform**: Android (Google Play Release Compatible)

## Key Features
- Preloaded Interstitial Ads (Every 5th article view)
- Preloaded App Open Ads (Startup + return from inactivity > 30s)
- Complete Notification System with Badge, Unread State, Mark as Read, Clear All
- Prepared Firebase Cloud Messaging Architecture
- Full RTL Support for Arabic Language News Standard
- Google Play News Policy Compliance Disclosures
- Performance Optimized Virtualized Lists with React.memo
